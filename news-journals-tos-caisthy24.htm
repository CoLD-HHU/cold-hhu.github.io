    FlatFS+：用扁平命名空间改善高速存储的元数据访问

    录用稿在线发表：2023-09-06　·　TOS　·　CCF A 类

    新型非易失性存储具有低延迟、可按字节访问的特点，但传统目录树带来的逐级路径查找与遍历开销，可能限制其优势发挥。唐斌参与的这项研究关注文件系统元数据管理如何适应更快的存储介质。

    论文提出 FlatFS+ 文件系统，内部使用扁平命名空间，同时向使用者提供兼容的层次化目录视图。系统结合直接文件路径访问、面向范围操作优化的树索引，以及兼顾扫描与写入的压缩索引键设计，改进元数据访问过程。

    论文通过元数据密集型基准和真实应用评估这一设计，报告了相对其他文件系统的性能改善。其意义在于调整命名空间和索引结构，使文件系统更充分地利用高速非易失性存储的性能特点。

    论文信息

    Miao Cai, Junru Shen, Bin Tang, Hao Huang, Baoliu Ye. Exploiting Flat Namespace to Improve File System Metadata Performance on Ultra-Fast, Byte-Addressable NVMs. ACM Transactions on Storage, 2024.

    第一署名单位：河海大学
    研究所作者：唐斌
